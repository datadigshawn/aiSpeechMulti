這個 mockup 是什麼？

這是 aiSpeechMulti 系統的 UI 預覽版。所有頁面之間可以正常互點，但所有「送出」「上傳」「辨識」「儲存」等按鈕不會真的做事，按下後右下角會跳提示 toast。

本階段目的：讓你針對 UI 長相、版面配置 提出意見，而非實際操作。回饋格式見 docs/mockup/README.md。

推薦動線
  1. 點 Capture 看現場錄音端的設定卡片
  2. 點 Monitor 看 6 路席位即時字幕 + 💰 成本 status bar
  3. 點 Display 看控制室大螢幕字體 + 關鍵字告警樣式
  4. 點 Lab 走完 9 個分頁（左側 sidebar 切換）
  5. 點 Grafana 看 7 大區塊 dashboard 布局
