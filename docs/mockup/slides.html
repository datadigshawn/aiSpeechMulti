PART 2

📁 語音檔案辨識

場景：拿一段錄音，想看辨識結果

Lab speech · 五步驟

  1. 選模型類別：google_stt / sensevoice / sensevoice_ft ⭐ / gemini / hybrid
  2. 選子模型：chirp_3 / chirp_3_hans / gemini-2.5-pro 等
  3. 上傳音檔：拖拉 wav/mp3/m4a/flac/ogg/aac
  4. 詞彙表設定：☑ 啟用詞彙加權（三層架構）
  5. 音訊前處理：VAD / DeepFilterNet 降噪

→ 按 🚀 開始辨識 → 顯示 raw + 4 階段後處理（car_norm → dict → contextual → LLM）+ 信心度色塊 + ✏️ 修正按鈕

→ 開啟 mockup Lab speech 頁

PART 4

📊 CER 評測 + 歷史查詢

量化辨識準確率 · 三種方式翻查歷史

Lab evaluation · 四步驟

  1. 選案例：頂部 dropdown 挑 experiments/ 子目錄
  2. 上傳音檔：拖到 source_audio 區
  3. 上傳 ground truth：.txt / .csv
  4. 上傳 ASR output：辨識結果 → 按 開始評測

結果顯示：CER %（紅 = 刪除 / 綠 = 新增 字元對照 diff）

CLI 版本（跑 6 引擎全批次）

python -m aispeech eval-batch
→ 結果存到 experiments/llm_correction_poc/cer_history.csv
→ python -m aispeech data sync-cer    # 同步到 Grafana
